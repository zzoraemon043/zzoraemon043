### About me

- I build **game tools** — asset editors, packers and animation utilities for 2D games
- I work a lot with **Spine** skeletal animation and **Live2D / VTuber** models
- I make **offline-first developer tools** that run entirely in your browser — nothing you paste ever leaves your machine
- I write in Traditional Chinese and English

### 關於我

- 開發**遊戲工具**：2D 遊戲的素材編輯器、封裝工具與動畫工具
- 常和 **Spine** 骨骼動畫、**Live2D／VTuber** 模型打交道
